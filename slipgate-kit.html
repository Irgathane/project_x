02 · Game feel

Tuning panel

These controls rewrite qc/tuning.qc live — no code editing needed. Move a slider, watch the source update, then download. This is the exact file your LLM should never hardcode values into.

Balanced defaults match classic Quake feel (270 jump velocity, 6×6 shotgun). Randomize stays inside sane ranges. “Monsters off” also skips precaching the monster model — useful while your asset folder is incomplete.
